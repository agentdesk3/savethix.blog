## 1. Copy the Instagram video link

1. Open Instagram and find the video or Reel.
2. Open the post menu or select **Share**, depending on the interface.
3. Choose **Copy link** if the option is available.
4. Check that you copied the link to the individual post, not just a profile.

Instagram can change its menus. If you cannot find the option, open the post in Instagram's website or app and check the available sharing options.

## 3. Save the video on Windows

On a Windows PC, use a current browser such as Chrome or Edge.

1. Start the download from the available result.
2. If prompted, choose a folder where you can find the file again.
3. If no location prompt appears, check the browser's downloads list.
4. Open **File Explorer** and select **Downloads**, unless you chose another folder.

In Chrome or Edge, open the browser's downloads list to check progress and use the option to show the file in its folder when available.

## 4. Save the video on a Mac

On macOS, you can use Safari, Chrome, or another compatible browser.

1. Open the downloader in your browser and submit the public Instagram post link.
2. Select an available download option.
3. If the browser asks where to save the file, choose a location you can access easily.
4. Otherwise, check the browser's download list and the configured Downloads folder.

In Safari, the Downloads button or download list can help you locate a finished file. In Chrome, open the downloads page and use the option to show the file in Finder when available. The exact controls may differ by browser version and settings.

## 5. Find and check the downloaded file

If the file is not where you expected, check these locations:

- **Windows:** Open File Explorer and check Downloads, or use your browser's download list.
- **Mac:** Open Finder and check Downloads, or locate the file from your browser's download list.
- **Custom location:** Check the folder you selected when saving the file.

Wait until the download finishes before opening it. If the file will not play, confirm that it is complete and that your media player supports its format. Do not assume that changing the file extension will convert it to another format.

## 6. Troubleshoot common download problems

- **The link is rejected:** Copy the link again from the individual video post and remove any extra text or spaces.
- **The post is private or unavailable:** The service may not access private, deleted, or restricted content. Do not try to bypass privacy controls.
- **No download option appears:** The particular post may not be supported, or the service may be temporarily unable to retrieve it.
- **The download stalls:** Check your connection, wait before retrying, and check whether your browser is asking for permission to download the file.
- **The file is missing:** Open the browser's download list and check the destination folder.
